# tiny-chess-01

A tiny chess engine entry for make.fun's "Build the strongest chess engine in 4 KB of Python" bounty: alpha-beta search with iterative deepening, a transposition table, piece-square tables and a deterministic node budget, packed into a 4 KB `main.py` with the kit's `makefun compress` command.

Run: `python3 main.py` (set `MAKEFUN_ENV_URL` to the trial server).
